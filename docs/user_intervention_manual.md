# SafeTalk User Intervention & Release Manual

This document details all operations requiring your manual intervention. Since SafeTalk is a client project, these integrations require account access, security configurations, and API credentials that only the owner can establish.

---

## 1. Firebase Secret Manager (Cloud Deploy)
Before deploying the Cloud Functions to production, you must set the production secret keys via the Firebase CLI.

Run the following commands locally:
```bash
# 1. Set Agora App Credentials
firebase functions:secrets:set AGORA_APP_ID="YOUR_PRODUCTION_AGORA_APP_ID"
firebase functions:secrets:set AGORA_APP_CERTIFICATE="YOUR_PRODUCTION_AGORA_APP_CERTIFICATE"

# 2. Set Razorpay API Credentials
firebase functions:secrets:set RAZORPAY_KEY_ID="YOUR_PRODUCTION_RAZORPAY_KEY_ID"
firebase functions:secrets:set RAZORPAY_KEY_SECRET="YOUR_PRODUCTION_RAZORPAY_KEY_SECRET"
```
*Note*: These values are stored in GCP Secret Manager and bound dynamically to your functions without exposing them in the source code repository.

## 2. Google Play Developer Console Configurations

### A. Create a Service Account for CI/CD Deployment
To allow GitHub Actions and Fastlane to upload your Android App Bundles automatically:
1.  Go to the [Google Cloud Console](https://console.cloud.google.com/).
2.  Select your Firebase project.
3.  Go to **IAM & Admin -> Service Accounts** and click **Create Service Account**.
4.  Name it `fastlane-uploader` and grant it the role of **Project -> Editor** (or specific Google Play Android Developer roles).
5.  Click on the newly created service account, go to the **Keys** tab, click **Add Key -> Create New Key**, select **JSON**, and download the file.
6.  Save this JSON content as a GitHub Secret named `PLAY_STORE_JSON_KEY`.

### B. Link the Service Account to the Play Console
1.  Open the [Google Play Console](https://play.google.com/console/).
2.  Go to **Setup -> Users and permissions**.
3.  Click **Invite new users** and enter the email address of the service account you just created in Google Cloud.
4.  Under **App permissions**, grant access to the SafeTalk app.
5.  Under **Account permissions**, check the following box:
    *   **Manage releases, draft releases, and upload APKs / App Bundles**.
6.  Send the invitation. Fastlane will now be authenticated to upload binaries on your behalf.

## 3. Play Store Closed Testing & Payments Setup

### A. Register Testers
Google requires new developer accounts to complete closed testing before publishing publicly:
1.  In the Play Console, navigate to **Testing -> Closed testing**.
2.  Create a track (e.g., "Alpha") and click **Manage track**.
3.  Go to the **Testers** tab.
4.  Add the email addresses of your testing team.
5.  Provide the testers with the opt-in link generated by Google Play to download the app.

### B. Payment Configuration for Testers
Since SafeTalk uses **Razorpay Standard Checkout** rather than Google In-App Purchases:
1.  Ensure the app is initialized with your **Razorpay Test Key** (`rzp_test_...`) during testing.
2.  Provide testers with mock transaction credentials:
    *   **Card Number**: Use standard dummy cards (e.g., `4111 1111 1111 1111`, expiry in future, any CVV).
    *   **UPI**: Select the "Success" simulation handler.
    *   **NetBanking**: Choose any bank and select "Success" on the redirect landing page.
3.  This verifies the backend state transition to `"active"`, triggering call invites and ledgers without executing actual bank payouts.
